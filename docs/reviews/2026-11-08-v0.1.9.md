**Top risks**

1. **There is no release pipeline.** All six fails are release-side: no license audit, no API check, no
   release build or dry run, no tag-to-version check, no changelog (`RA-CICD-013/014/017-020`).
   - `release.yml` is a placeholder that fails on purpose. The workspace version is still `0.0.0` while
     milestones are already named `v0.1.x`.
   - v0.1.9 made the PR-side gates fail safe. The release side has no gates at all.
2. **Local verification is weaker than CI.**
   - `ruse verify --full` runs clippy without `-D warnings` (`spec/verification.yaml:18`).
   - It also skips the locked fetch, the install smoke, the `tools/tests` unit tests, actionlint and
     `cargo audit`.
   - CI runs its own list of steps instead of calling `verify` (`ci.yml:64-85`), so a green pre-push hook
     does not predict a green CI (`RA-RUSE-006`, `RA-CICD-001/002`).
3. **Specs and docs say more than is enforced.**
   - 4 of 8 constitution articles are machine-enforced. So are 3 of 8 fitness functions and 1 of 138
     `machine` review axes.
   - `spec/CONTEXT.md` stops at D-060 and still says "v0 journal shipped" (RJ01, D-064, has landed).
   - `F-001` is `status: done` but `gov implementable` reports NOT-READY (`RA-RUSE-001/002/005/010`).
4. **Parity is broad but not closed.**
   - 4185 nvim fixtures and 152 Emacs fixtures are oracle-captured and ratcheted.
   - 136 Vim divergences are still allowed (`tests/parity/vim/known-divergences.txt`). #1302 alone
     covers 104 change-mark fixtures.
   - Fuzzing runs weekly with no committed seed corpus.
5. **Gaps in the persistence and large-file story are known and filed.**
   - Above 32 MiB the editor only degrades the profile. It still reads the whole file into memory (#1290).
   - The journal drops `'endoffile'`, `'fileformat'` mac and `'binary'` (#1286).
   - No journal fixtures from past releases are checked in.

## Follow-ups

Each item is a real gap from a fail or partial row. These are proposals, not filed issues. Gaps already
tracked are not proposed again: #1264, #1259, #1290, #1286, #926, #904 and #1298-#1307.

Each item below gives the proposed issue title, the axes it covers, and the gap.

1. **`build(verify): make ruse verify --full run the steps CI runs`** (`RA-RUSE-006`, `RA-CICD-001/002`).
   - `spec/verification.yaml` runs clippy without `-D warnings`.
   - It skips `cargo fetch --locked`, the install smoke, `tools/tests`, actionlint and `cargo audit`.
   - CI runs its own step list. Either CI calls `verify --full`, or a test asserts that the two lists
     agree, so a green pre-push means a green CI.
2. **`build(ci): add a cargo-deny license and bans check`** (`RA-CICD-013`). `ci-cd-and-release.md` §11
   requires a license check and none exists. Add `deny.toml` and a job, advisory first.
3. **`spec(release): decide how the workspace version follows milestone versions`** (`RA-CICD-019/020`).
   - Milestones are named `v0.1.x`, but `Cargo.toml` is `0.0.0` and no tag exists.
   - Decide whether the release workflow (#926) stamps the version, checks the tag against it and
     generates the changelog from conventional commits. Then add those steps to #926 or file them next to it.
4. **`build(cargo): declare rust-version and check the MSRV in CI`** (`RA-CICD-007`). Only the pinned
   toolchain is tested; the minimum supported Rust is undeclared.
5. **`fix(spec): CONTEXT.md lags DECISIONS (D-061 to D-064) and the RJ01 journal`** (`RA-RUSE-002/005`).
   - The digest that agents read first stops at D-060 and describes the v0 journal.
   - Refresh it, or add a check that it cites every decided `D-*`, until the generator (D-022) lands.
6. **`fix(spec): F-001 is done but gov implementable reports NOT-READY`** (`RA-RUSE-010`). F-001 cites only
   the legacy parity ids COM-7, VIM-UNDO-1 and EMACS-EDIT-1. Repoint them to census ids, or make
   `gov check` fail when a done feature is NOT-READY.
7. **`test(lsp): a server that hangs or dies mid-session leaves the editor responsive`** (`RA-RUSE-009`).
   - Only spawn failure and exit are tested.
   - Add a PTY or headless test with a fake server that stops answering, and one that exits mid-request.
     Assert that editing, saving and quitting still work.
8. **`docs(architecture): one table of state, authority, process and trust boundaries`** (`RA-RUSE-007`,
   `RA-STATE-006`).
   - The boundaries are explicit per module but not in one inventory.
   - The table should give each boundary's owner, its process, what crosses it, what is trusted, and
     which state persists across a restart.
9. **`test(persist): replay journals written by earlier releases`** (`RA-TEST-016`). Check in small RJ01
   and RJS0 files from past releases and assert that they still recover. Format drift then fails a test.
10. **`build(fuzz): commit minimized seed corpora and run a short PR fuzz smoke`** (`RA-TEST-009`). Weekly
    cold-start runs lose coverage between runs and catch regressions only after merge.
11. **`test(ci): a machine-checked quarantine list with owner and expiry`** (`RA-TEST-026`). The policy
    exists, but 8 `#[ignore]` tests (#602) have no expiry. A gov check should fail on an ignored test
    that is not on the list, or whose expiry has passed.
12. **`spec(gov): link capabilities and acceptance criteria to tests`** (`RA-TEST-030`, `RA-RUSE-010`).
    Feature-level `trace.verify` exists. `capabilities.yaml`, DR-* entries and per-criterion acceptance
    have no test links.
13. **`test(config): compare schema default values with the loader defaults`** (`RA-DOC-017`).
    `schema_matches_spec` checks every column except `default:`, so a documented default can drift.
14. **`docs(architecture): the keybindings example names keys the schema does not have`** (`RA-DOC-017`).
    `architecture.md:289` shows a `[[keybindings]]` table. Mark it as future design, or rewrite it to the
    `keymap.*` schema.
15. **`feat(log): say when RUSE_LOG cannot be opened`** (`RA-ARCH-027`). A bad path turns logging off
    silently. Report it on the status line or as a `:checkhealth` row.
16. **`fix(tools): put timeouts on the bench, phase_sync and fetch subprocess calls`** (`RA-TOOL-017`). A
    hung `gh` or `cargo` stalls until the job is killed.
