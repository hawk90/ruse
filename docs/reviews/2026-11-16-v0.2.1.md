**Method.**
- `machine` axes: of the 49, four have an `automated_by` checker: `RA-ARCH-003` (spec-validate),
  `RA-ARCH-007` and `RA-ARCH-008` (dependency-check), `RA-ARCH-040` (design_code). All four were run. Every
  other `machine` axis is marked **unwired**; its verdict comes from a measurement or gate run for this report.
- Structure figures come from a throwaway script, run on `cc81e245` and on the v0.2.0 pin `e8a2f670`
  (`git archive`). It is not committed. It reads `crates/*/src` and `apps/*/src`, blanks comments and string
  and char literals, and measures a function from its `fn` line to its closing brace. It excludes the
  generated `case_tables.rs`, test files (`tests.rs`, `*_tests.rs`, anything under a `tests/` directory)
  and functions inside `#[cfg(test)]` modules. `crates/core/src/editor/ex_cmd/samples.rs::samples`
  (208 lines) is a `#[cfg(test)] fn` (`samples.rs:8`), so it is left out of the counts below as well.
- Path freshness comes from a second throwaway script. It resolves every `apps/…`, `crates/…`, `tools/…`
  and `fuzz/…` path, `path:line` and `path::name` reference in `docs/` (without `docs/reviews/`), `spec/`,
  `AGENTS.md`, `CONTRIBUTING.md` and `README.md`.
- `llm` and `mixed` axes: assessed by reading the code at the cited lines.
- `manual` axes: marked **needs maintainer**, with what to look at.
- A verdict without evidence is not a pass.
- Security-relevant findings are withheld: their rows say only "details reported privately". This
  report has none.
- "Moved" compares with `docs/reviews/2026-11-16-v0.2.0.md`. "new" means the axis was not in that report.

**Moved since v0.2.0:** none of the 17 axes in both reports changed verdict. `RA-RUSE-008` and
`RA-ARCH-007` stay `pass` on a scan that now covers more files (txn-only mutation 158 → 265 files,
input → frontend 17 → 30), because the splits created more files, not because the rules changed.

**Top risks**

1. **The new module boundaries are mostly not visible in imports.**
   - 62 non-test child modules begin with `use super::*;` (3 at v0.2.0). Most are in
     `editor/planner/` (13), `app/session/` (11), `workspace/` (7) and `ui/render/` (7).
   - A child module sees every item of its parent. So its imports do not say what it depends on, and
     nothing stops a later change from reaching back into any parent item.
   - 24 call sites in `app/session/` still pass the same five session fields to the free `run_cmd`. They
     are inside a `let Session { … } = self` destructure that keeps borrowing other fields (#1448's body:
     "Not converted (24)").
2. **Nothing holds the new sizes.**
   - No gate measures file or function size (`RA-STRUCT-005` is unwired). 19 functions are still over 150
     lines and 15 files over 1,000. Five of those functions came out of v0.2.1's own splits
     (`g_command` 187, `base_grammar` 185, `operator::plan` 185, `normal_chord_owns` 166, `z_fold` 162).
   - The milestone's 200-line target is met (0 functions of 200+), but only by review, so the code can
     grow back past it unnoticed.
3. **Source-path references in docs and spec are unchecked, and the splits broke some.**
   - `docs check` validates Markdown links, not source paths. Of 500 path references, 5 paths (8
     references) no longer resolve.
   - Four of them were broken by this milestone: files that became directories (`crates/core/src/command.rs`,
     `editor/ex_cmd.rs`, `workspace.rs`).
   - One `path::name` evidence reference has been stale since #1200 (`spec/design-requirements.yaml:1632`).
   - The split PRs did repoint the design docs and `spec/PRD.yaml` / `spec/design-requirements.yaml`
     (15 spec/doc files changed, 17 lines in those two files). So this is the residue, and it has no check.
4. **The context digest still lags** (carried from v0.2.0, #1360, v0.2.4). `spec/CONTEXT.md` ends at
   D-064 (`:86`) and has no D-065 or INV-TEXT-TERMINATED.
